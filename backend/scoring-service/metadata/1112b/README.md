## 적용

1. 현재 모델 artifact 전체와 score_cuts.json·등록 메타데이터를 별도 위치에 백업한다.
2. 모델별 새 artifact 경로에 기존 가중치·토크나이저·config·train_info를 복사하고 해당 b판 score_cuts.json으로 교체한다. 활성 경로를 덮어쓰지 않는다.
3. 기존 사전 검사와 등록·승인 절차를 거쳐 새 artifact를 로딩한다. 승인 scope와 모델 버전은 유지한다. 파일만 교체하면 이미 로딩된 모델에는 반영되지 않는다.
4. 실제 요청의 모델 revision과 새 정수 경계를 확인한다. `scripts/verify_m2_text_guards.py`로 로컬 재로딩·복귀를 검증할 수 있다.

## 복귀

이전 artifact 경로와 메타데이터로 재로딩한다. 원점수는 동일하고 이전 경계 기반 정수 점수로 돌아오는지 확인한다.
전처리·긴 글 방식까지 되돌릴 때는 #549 이전 서비스 이미지로 복귀한다. 모델 활성화·content3 설정은 임의로 변경하지 않는다.

이 저장소 반영은 운영 S3 업로드·운영 모델 활성화가 아니다. #549는 로컬 복사본에서 두 모델의 경계 적용·재로딩·복귀를 검증한다.
