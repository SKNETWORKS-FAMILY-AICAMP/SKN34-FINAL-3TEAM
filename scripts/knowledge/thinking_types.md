# 생각 유형 근거와 출제 지침 (#465, #262 기준)

작성 2026-11-11 · 기준: [functional-spec 1.5](../../docs/design/functional-spec.md) 생각 유형·표준 요소(#262, 11/03), 프로젝트 기획서 5.3

`사고뭉치_평가_루브릭_근거와_출처.md`(2026-10-26, 저장소 밖)를 #262 결정에 맞춰 고쳐 쓴 문서다. 아래 "레코드" 절은 `extract_curriculum.py`가 읽어 지식 RAG 추출 레코드(`kind: thinking_type`, 계약 C1) 5개로 옮긴다. 출제 지침 문장은 팀이 우리 말로 쓴 **기준안(팀 확인 전)**이다.

## 1. 지켜야 할 것

- 블룸 개정 분류 원서(Anderson & Krathwohl, 2001)와 AAC&U VALUE 루브릭의 문장(수준별 설명 등)은 옮기거나 번역해 넣지 않는다. VALUE는 CC BY-NC-SA 4.0이라 상업적 데이터베이스·평가 소프트웨어에 쓰려면 AAC&U 사전 서면 허가가 필요하고, 블룸 원서는 저작권 있는 출판물이다
- 출처 표기는 "블룸 개정 분류(Anderson & Krathwohl, 2001)의 '분석' 개념을 참고", "AAC&U VALUE 비판적 사고 루브릭의 항목을 참고"처럼 참고했다는 사실만 쓰고, AAC&U가 검토하거나 보증한 것처럼 보이지 않게 한다
- 영어 원문은 항목 이름 정도만 남긴다
- 평가원 성취수준 문장은 넣지 않는다(이용 조건 확인 전, FN 1.5). 10/26 문서의 "연결 성취기준·성취수준 A 문장" 표는 이 문서에서 뺐다

## 2. 10/26 문서에서 바뀐 점

| 항목 | 10/26 문서 | 지금(#262, 11/03) |
|---|---|---|
| 돌아보기 요소 | ① 자기 생각 과정 ② 무엇이 바뀌었는지 | ① 바뀐 생각 ② 바뀐 까닭 ③ 생각 과정·경험과 연결(`REFLECT_CHANGE`·`REFLECT_REASON`·`REFLECT_CONNECT`). 시드 미션 질문이 바뀐 생각과 까닭을 묻고 "자기 생각 과정"은 따로 묻지 않아 세 번째 요소로 옮김 |
| 따져 보기 ③ 근거 항목 | VALUE 비판적 사고의 'Influence of context and assumptions' 항목 | 같은 루브릭에서 다른 관점을 인정하는지 보는 부분(`EVALUATE_PERSPECTIVE`, [learning 20절](../../docs/report/learning.md) 표준 코드 표). 이름은 "다른 관점·반론" |
| 분석하기 | 구별·조직하기와 탐구·분석 루브릭을 함께 근거로 | 기획서 2요소 그대로(`ANALYZE_RELATION`·`ANALYZE_REASON`). 블룸 개정 분류에서 분류·비교는 '이해' 쪽이고, '분석'은 나눈 부분 사이의 관계까지 본다는 개념만 참고 |
| 원문 인용 | 영어 항목 설명을 괄호로 함께 적음 | 항목 이름만 |
| 성취기준 연결 | 유형별 예시 성취기준과 성취수준 A 문장 | 성취수준 문장은 뺌. 유형과 성취기준의 짝은 관계 후보(#468)에서 사람이 확인 |
| 판정 | 요소별 있음/없음 + 근거 구절 | 같음(FN-JDG-03). VALUE 4단계 점수는 쓰지 않음 |

## 3. 유형별 근거 요약

| 유형 | 코드 | 근거 틀(이름만) | 평가 요소(#262 표준 코드) |
|---|---|---|---|
| 분석하기 | `ANALYZE` | 블룸 개정 분류 '분석' | 원인·특징·관계, 까닭 잇기 |
| 따져 보기 | `EVALUATE` | AAC&U VALUE 비판적 사고 루브릭(항목: Student's position, Evidence) | 주장, 근거, 다른 관점·반론 |
| 새로 만들기 | `CREATE` | AAC&U VALUE 창의적 사고 루브릭(항목: Innovative Thinking; Connecting, Synthesizing, Transforming; Solving Problems) | 새로운 생각, 왜 나은지, 연결·변형 |
| 문제 해결하기 | `SOLVE` | AAC&U VALUE 문제 해결 루브릭(항목: Define Problem, Identify Strategies, Evaluate Outcomes) | 문제 정하기, 방법 세우기, 결과 확인 |
| 돌아보기 | `REFLECT` | AAC&U VALUE 평생학습 루브릭(항목: Reflection), 메타인지(Flavell, 1979) | 바뀐 생각, 바뀐 까닭, 생각 과정·경험과 연결 |

- 다섯 유형 묶음은 팀이 서비스 목적에 맞게 구성한 틀이며 표준이라고 주장하지 않는다(FN 1.5 한계). VALUE 루브릭은 대학생용이라 학년 수준은 미션마다 연결한 성취기준이 맞춘다
- 필수 요소인지 들어가면 좋은 생각인지는 코드가 아니라 미션 요소마다 정한다(FN 1.5). 그래서 레코드의 `requiredDefault`는 비운다(null)

## 4. 레코드

아래 형식을 바꾸면 `extract_curriculum.py read_thinking_types`도 같이 고친다. 근거는 `- 틀 이름 | 출처 표기`, 요소는 `- 코드 | 이름 | 공통 설명`, 나머지는 `- 문장` 한 줄씩이다.

## 레코드: ANALYZE 분석하기

### 근거

- 블룸 개정 분류 | 블룸 개정 분류(Anderson & Krathwohl, 2001)의 '분석' 개념을 참고해 팀이 우리 말로 정리함. 원서 문장은 넣지 않음
- 사고뭉치 기획서 5.3 | 프로젝트 기획서 5.3 생각 유형 표(평가 요소 ① 원인·특징·관계 ② 까닭 잇기)

### 요소

- ANALYZE_RELATION | 원인·특징·관계 | 원인과 결과, 특징, 부분 사이의 관계를 말함
- ANALYZE_REASON | 까닭 잇기 | 말한 원인·특징·관계를 까닭으로 이어 설명함

### 질문에 꼭 넣을 것

- 자료·이야기·현상 속에서 원인과 결과, 특징, 부분 사이의 관계 가운데 하나 이상을 학생이 직접 찾아 말하게 한다.
- 찾은 관계를 왜 그렇게 보았는지 까닭과 이어 설명하게 한다.
- 연결한 성취기준의 행동(문장의 동사)과 그 학년·학기까지 배운 개념 안에서 묻는다.

### 질문에 넣지 않을 것

- 글에 이미 적힌 답을 찾아 옮겨 쓰기만 하면 되는 질문(#437 텍스트 시험에서 나온 사례).
- 분류하거나 비교하는 것으로 끝나는 질문. #262 결정에서 분류·비교는 '이해' 쪽으로 보아 분석하기로 내지 않는다.

### 메모

- 출제 지침 문장은 팀이 새로 쓴 기준안이며 팀 확인 전
- requiredDefault는 FN 1.5('필수 여부는 미션 요소마다 정함')에 따라 비움

## 레코드: EVALUATE 따져 보기

### 근거

- AAC&U VALUE 비판적 사고 루브릭 | AAC&U VALUE 비판적 사고 루브릭의 항목을 참고해 팀이 우리 말로 정리함. 루브릭 원문·수준별 설명은 넣지 않았고, AAC&U의 검토나 보증을 받은 내용이 아님
- 사고뭉치 기획서 5.3·#262 | 프로젝트 기획서 5.3 생각 유형 표(① 자기 주장 ② 근거 ③ 다른 관점·예외 고려)와 ③을 '다른 관점·반론'으로 정한 #262 표준 코드(docs/report/learning.md 20절)

### 요소

- EVALUATE_CLAIM | 주장 | 자기 주장(입장)을 밝힘
- EVALUATE_EVIDENCE | 근거 | 주장을 뒷받침하는 근거를 말함
- EVALUATE_PERSPECTIVE | 다른 관점·반론 | 다른 관점·반대 의견·예외를 생각하고 답함

### 질문에 꼭 넣을 것

- 학생이 한쪽 입장을 고를 수 있는 상황을 주고 자기 주장을 밝히게 한다.
- 주장을 뒷받침하는 근거를 대게 한다.
- 다른 생각이나 반대 의견, 예외를 하나 떠올려 답하게 한다. 따져 보기 논술 미션은 세 요소를 모두 묻는다(#262).

### 질문에 넣지 않을 것

- 답이 하나로 정해져 있어 따질 거리가 없는 질문.
- 근거 없이 좋고 싫음만 고르게 하는 질문.

### 메모

- 출제 지침 문장은 팀이 새로 쓴 기준안이며 팀 확인 전
- requiredDefault는 FN 1.5('필수 여부는 미션 요소마다 정함')에 따라 비움

## 레코드: CREATE 새로 만들기

### 근거

- AAC&U VALUE 창의적 사고 루브릭 | AAC&U VALUE 창의적 사고 루브릭의 항목을 참고해 팀이 우리 말로 정리함. 루브릭 원문·수준별 설명은 넣지 않았고, AAC&U의 검토나 보증을 받은 내용이 아님
- 사고뭉치 기획서 5.3 | 프로젝트 기획서 5.3 생각 유형 표(평가 요소 ① 기존과 다른 생각 ② 연결·변형 ③ 왜 나은지 설명)

### 요소

- CREATE_NEW | 새로운 생각 | 기존과 다른 새로운 생각을 냄
- CREATE_WHY | 왜 나은지 | 자기 생각이 왜 더 나은지 설명함
- CREATE_CONNECT | 연결·변형 | 다른 것과 연결하거나 바꾸어 생각을 만듦

### 질문에 꼭 넣을 것

- 기존과 다른 자기만의 생각(물건·방법·이야기 등)을 내게 한다.
- 그 생각이 왜 더 나은지 설명하게 한다.
- 다른 것과 연결하거나 바꾸어 만들 여지를 준다.

### 질문에 넣지 않을 것

- 보기 가운데 하나를 고르기만 하면 되는 질문.
- 정해진 답을 그대로 따라 쓰게 하는 질문.

### 메모

- 출제 지침 문장은 팀이 새로 쓴 기준안이며 팀 확인 전
- requiredDefault는 FN 1.5('필수 여부는 미션 요소마다 정함')에 따라 비움

## 레코드: SOLVE 문제 해결하기

### 근거

- AAC&U VALUE 문제 해결 루브릭 | AAC&U VALUE 문제 해결 루브릭의 항목을 참고해 팀이 우리 말로 정리함. 루브릭 원문·수준별 설명은 넣지 않았고, AAC&U의 검토나 보증을 받은 내용이 아님
- 사고뭉치 기획서 5.3 | 프로젝트 기획서 5.3 생각 유형 표(평가 요소 ① 문제가 무엇인지 말함 ② 방법을 세움 ③ 결과를 확인함)

### 요소

- SOLVE_DEFINE | 문제 정하기 | 무엇을 구하거나 해결해야 하는지 말함
- SOLVE_PLAN | 방법 세우기 | 해결 방법이나 순서를 세움
- SOLVE_CHECK | 결과 확인 | 결과가 맞는지 확인함

### 질문에 꼭 넣을 것

- 무엇을 구하거나 해결해야 하는지 학생이 먼저 말하게 한다.
- 해결 방법이나 순서를 세우게 한다(수학은 풀이 단계 틀).
- 구한 결과가 맞는지 확인하게 한다.

### 질문에 넣지 않을 것

- 식이 주어져 계산만 하면 끝나는 질문(#437 텍스트 시험에서 나온 사례).
- 그 학년·학기까지 배우지 않은 개념을 써야 풀리는 질문.

### 메모

- 출제 지침 문장은 팀이 새로 쓴 기준안이며 팀 확인 전
- requiredDefault는 FN 1.5('필수 여부는 미션 요소마다 정함')에 따라 비움

## 레코드: REFLECT 돌아보기

### 근거

- AAC&U VALUE 평생학습 루브릭(성찰 항목)·메타인지 | AAC&U VALUE 평생학습 루브릭의 성찰 항목 이름과 메타인지 개념(Flavell, 1979)을 참고해 팀이 우리 말로 정리함. 루브릭 원문·수준별 설명은 넣지 않았고, AAC&U의 검토나 보증을 받은 내용이 아님
- 사고뭉치 #262 결정 | 돌아보기 요소를 바뀐 생각·바뀐 까닭·생각 과정·경험과 연결로 정한 #262 결정(docs/report/learning.md 20절)

### 요소

- REFLECT_CHANGE | 바뀐 생각 | 처음 생각(방법)과 바뀐 생각(방법)을 말함
- REFLECT_REASON | 바뀐 까닭 | 생각이나 방법이 바뀐 까닭을 말함
- REFLECT_CONNECT | 생각 과정·경험과 연결 | 자기 생각 과정이나 경험과 연결해 말함

### 질문에 꼭 넣을 것

- 처음 생각(방법)과 바뀐 생각(방법)을 함께 말하게 한다.
- 생각이 바뀐 까닭을 말하게 한다.
- 자기 생각 과정이나 경험과 이어 말하게 한다.

### 질문에 넣지 않을 것

- 앞으로의 다짐이나 계획만 묻는 질문. #262 결정에서 다짐은 실제로 적용한 것이 아니라고 보았다.
- 느낌만 묻고 생각이 어떻게 바뀌었는지는 묻지 않는 질문.

### 메모

- 출제 지침 문장은 팀이 새로 쓴 기준안이며 팀 확인 전
- requiredDefault는 FN 1.5('필수 여부는 미션 요소마다 정함')에 따라 비움
