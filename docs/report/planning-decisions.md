### 2.2 유형별 성취기준을 고른 근거

### 2.3 M2 중간 결과 (11/2 기준, 모델링 진행 중)

허용 기준이 정해지지 않아 통과·미달 판정은 하지 않음. 활성화 판단(NFR-AIQ-06, 11/22) 전까지 숫자는 바뀔 수 있음.

- 지표: M2 담당 보고 숫자는 Pearson 상관("일치도"가 아니라 "상관"). 대표 숫자는 **처음 보는 주제**(주제 자체가 학습에 없던 글, 자체 미션에 M2를 쓰는 서비스 상황) 값이며 **모델 대 전문가 평균** 방식(#213 담당 결정 11/2). 사람끼리는 전문가 1대1이 기준선
- 서비스 후보 모델은 모든 주제를 학습하므로 처음 보는 주제 값은 같은 설정으로 일부 주제를 빼고 학습한 평가용 모델로 구함

| 구분 | 모델 | 모델 대 전문가 평균 | 사람끼리 |
|---|---|---:|---:|
| 처음 보는 주제 (대표) | 논술 3.1 설정, 주제 10개 제외(9,296편) | 총점 0.45~0.48 (같은 분할 2회 0.452·0.476) | 1대1 0.560, 1명 대 나머지 0.633 |
| 처음 보는 주제 (대표) | 서술 3.0 설정, B안(학년×교과 20칸마다 1주제 제외, fold 3개 평균) | 총점 0.538 (0.516~0.551) | 1대1 0.694 |
| 학습한 주제 (참고) | 서술 3.0, AI Hub VL 4,000편 | 총점 0.685 | 1대1 0.694 |
| 학습한 주제 (참고) | 논술 3.1, AI Hub VL 5,883편 | 총점 0.700 (구성 0.780·내용 0.694·표현 0.481, 초등 0.561) | 1대1 0.718 |

- 약한 곳: 처음 보는 주제 성능이 학습한 주제보다 크게 낮음. 학습한 주제로 학습 멈춤을 정하면 처음 보는 주제에 약해지는 것으로 보임(M2 담당 추정, 검증 주제를 따로 빼 학습 멈춤·경계를 정하는 실험 중). 논술 표현이 사람끼리보다 0.16 낮음. 학습한 주제만 출제하는 문항 은행 방식은 학년별 주제가 서술 12개·논술 6개뿐이라 어려움

- 지난 숫자와 다른 이유: 멘토링의 서술 0.3·논술 0.4는 초기 모델의 QWK(처음 보는 지시문 조건)라 지금 숫자와 직접 비교하지 않음. 논술 0.734 → 0.681은 학습·평가에 같은 글이 들어간 126묶음 제거 결과(이후 3.1에서 0.700). 논술 데이터 71819 → 545는 채점자끼리 일치가 더 높아서
- 출처: M2 담당 정리(11/2), [ml/m2 README](../../ml/m2/README.md), 예측 CSV 계산(저장소 밖)

## 3. 설명 sLLM 데모 범위 재포함 (11/10, #473)

### 3.1 결정과 배경

P15(11/01, #213)로 범위에서 뺀 설명 sLLM(FN-RPT-09, NFR-AIQ-03)을 12/7 데모 범위에 다시 넣는다. M2 점수는 판정 교차 확인에만 쓰이고 숫자 레벨·등급 비표시 정책 때문에 학부모에게 전달되지 않는다. 설명 sLLM은 학생 글과 M2 항목 점수로 학부모가 읽을 설명을 만든다.

sLLM이어야 하는 이유: 학습 데이터인 AI Hub 71818 전문가 이유 문장은 외부 LLM API로 보낼 수 없다. 이 데이터로 학습하려면 직접 운영하는 모델만 가능하다.

| 항목 | 결정 | 근거 |
|---|---|---|
| 범위 | 12/7 데모 포함, 허용 기준 11/22(NFR-AIQ-06) | 기존 설계(FN-RPT-09·NFR-AIQ-03·UC-16)를 재사용해 새 기획이 적음 |
| 학부모 말투 | 규칙 후처리(점수·등급·숫자 표현 제거, 학부모용 문장 틀) | 전문가 문장은 채점자 말투이고 점수 표현이 섞임. 생성형 AI로 바꾼 문장은 학습에 쓸 수 없음(NFR-DAT-03) |
| 학습 위치 | RunPod, AI Hub 데이터만 | M2 학습 환경 재사용 |
| 생성 위치 | EKS 안 CPU 양자화 모델 | AWS 서울 리전은 개인정보 처리 위탁 목록에 이미 있어 동의서 변경이 없음(RunPod는 위탁·국외 이전 추가 필요). GPU 할당량 승인 대기 위험이 없음. 데모 규모(주 수십~수백 건)는 CPU로 충분하다고 추정 |
