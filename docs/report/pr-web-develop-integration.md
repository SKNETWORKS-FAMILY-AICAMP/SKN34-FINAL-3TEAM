# feat: 프론트 요구사항 보완 및 최신 develop 통합 (#93, #97, #134)

누락된 문의·알림·계정 관리 화면을 보완하고 관리자 모델 API와 인증 호출을 정리했습니다. 실제 자녀 응답에 plan이 없을 때 리포트 내용을 잘못 숨기던 문제를 수정하고, 최신 develop과 충돌하던 지원 화면 경로를 조정했습니다.

기존 PR #124를 대체하는 통합 PR입니다. #124의 변경과 #134 후속 수정을 포함하며 대상은 develop입니다.
관련 이슈: #93, #97, #134 · 이용권 후속: #129

## 주요 변경
- 요구사항 165개 대조 결과와 역할별 도움말·공지·문의·오류 신고·알림·계정 관리 화면 추가
- 삭제·탈퇴는 Google 재확인 후 접수하며, 실제 삭제 완료와 구분
- 관리자 모델 레지스트리의 구조화된 평가 근거, 승인·활성화·되돌리기 및 AI 호출 종류·미집계 비용 계약 반영
- 실제 모드의 이메일 로그인·가입·비밀번호 재확인 호출 제거, 개발 전용 모듈로 분리
- 학생 학습·로그인 화면의 로고 제거, 개발 전용 PIN 5090 체험 유지
- plan 미제공을 무료로 단정하지 않고 서버 응답을 기준으로 리포트 서술·저녁 질문을 표시하며 숫자·인용 대조 검사
- 리포트 목록을 core의 {items} 계약으로 통일하고, 자녀 PATCH는 변경한 선택 필드만 재확인 헤더 없이 전송
- 최신 develop의 /support 경로 충돌 해결: 신고·문의 알림의 reportId/inquiryId 링크와 결과 조회, 기존 접수 화면을 모두 유지하고 중복 경로 제거
- 요구사항 대조 보고서, 화면설계서 v2.1, 시스템 아키텍처·구조도 및 생성 소스 포함

## 검증
- 최신 develop 통합 작업본에서 단위·계약 테스트 111개 통과
- TypeScript·Vite 빌드·lint·운영 번들의 개발 목업 제외 검사 통과
- 운영 빌드와 Chrome 두 탭의 API 대역 브라우저 검사 통과
  - 학부모 신고·문의 알림 링크, 결과 목록, 접수 화면 및 학생 결과 조회 진입
  - 동시 refresh 최대 1회, 학생 refresh 미사용, 페이지 오류 없음
- 미해결 충돌 파일 없음, git diff --check 및 staged 공백 검사 통과

## 한계 및 후속
- 실제 DB·Google OAuth·백엔드·PG 통합 검증은 수행하지 않았습니다. 브라우저 검증은 API 대역 기준입니다.
- 기존 문의 접수·공지·관리자 답변의 제안 DTO는 최신 core 지원 계약과 추가 정합화가 필요합니다. 이번 라우팅 해결을 지원 기능 전체의 실서버 연동 완료로 해석하지 않습니다.
- 이용권 공급자·조회 계약 연동(#129)과 알림 실시간 SSE 수신은 포함하지 않습니다.
- 요구사항 대조 당시 남은 프론트 항목은 29개입니다. 새 백엔드 기능에 따른 재대조가 필요합니다.
- 기존 parent-admin-browser 전체 실행의 학생→학부모 전환 실패는 해결 확인하지 않았습니다.
- JS 청크 500kB 초과 경고가 남아 있습니다.
- 흑백 관리자 UI 별도 작업본과 구버전 v2.0 PDF·로컬 인수인계 파일은 포함하지 않습니다.
