### 키보드·초점

- 99회 Tab 이동에서 초점이 화면 밖·안 보이는 요소로 간 경우 0
- 본문 건너뛰기: 학부모 작업 화면 12화면(1440·390 24회)·관리자 15메뉴+미션 편집(31회)은 첫 Tab이 "본문으로 건너뛰기"·"본문으로 이동". 학생 화면·온보딩·자녀 추가·창은 없음(axe `bypass` 통과, 참고)
- 초점 표시 변화가 자동으로 안 잡힌 곳: 내 방 그림(1440·390, 표시가 바깥 칸 `.st-mini-room`의 안쪽 테두리라 스크립트가 못 잡음, `room.css` `:has(.st-room-stage:focus-visible)`로 확인), 관리자 390 게시 관리·주간 테마 검수 날짜 입력(보조 확인에서 Tab 초점에 `:focus-visible` 3px 외곽선 확인, 자동 측정 오탐). 둘 다 문제 아님
- 대화 창: 학부모 리포트 창은 Esc로 닫히고 초점이 연 단추로 돌아감
