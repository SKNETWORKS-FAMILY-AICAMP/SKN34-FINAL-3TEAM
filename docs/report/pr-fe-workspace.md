## 한계 및 후속
- 이번 검증은 프론트엔드·MSW 기준이며 실제 backend·인증 쿠키·DB·AI·PG·S3·전체 앱 배포·부하 검증은 포함하지 않았습니다.
- api-spec 3.8~3.10의 목업 DTO는 담당자 확인 후 실제 Controller/OpenAPI에 맞춰야 합니다. 3.7도 목업 인증 보완 계약입니다.
- 확정 P02에 따라 다른 보호자의 기존 학생 연결은 미지원입니다. P05에 따라 메모는 서버 초안 저장·학생 본인만 열람하며, 오래된 이슈의 로컬 전용 문구를 그대로 구현하지 않았습니다.
- 새로 등록한 자녀는 FREE입니다. 연속 테스트의 프리미엄 전제는 DEV+MSW 전용 가상 자녀 설정이며 결제·무료 체험·운영 권한 부여를 구현한 것이 아닙니다.
- 장면 파일 업로드 API가 없어 장면 URI만 지원합니다. 실제 큐 재처리·모델 평가/활성화·정정 결과 전파·주간 스케줄 생성·PDF 렌더러 통합은 후속입니다.
- 공통 기반과 각 역할 화면은 같은 PR에 포함되어 있으며, 독립적인 공통 기반 선행 PR으로 분리하지 않았습니다.
- 기존 GitHub 체크박스 갱신은 쓰기 권한 오류로 미반영 상태입니다. 이 PR의 검증 기록과 원격 체크 수는 다릅니다.
- 원격 CI는 PR 생성 후 확인해야 합니다.
