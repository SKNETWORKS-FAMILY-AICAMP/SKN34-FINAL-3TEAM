## 설계·발표 참고 피드백

- 에이전트성: 오케스트레이터 에이전트가 서브 에이전트·함수 수준 기능을 조합하는 구조를 단순 LLM 함수 호출과 구별해 설명한다.
- 판정 보류: LLM 서버 장애 시 판정 보류 → 복구 후 재처리 흐름을 설명한다.
- 학습 정답(GT): 전문가 2인 채점 평균을 쓰지만 채점 근거가 없어 학습 신뢰도 문제가 있다. 전문가 간 일치도는 약 0.69다.
- Node.js와 React 조합 시 버전 호환성을 확인한다.
- 커뮤니티(다른 학생 풀이 공유·포인트 경쟁)와 게이미피케이션(포인트·웹샵·굿즈) BM은 리텐션 방안으로 계속 검토한다.
- 학부모가 공개를 강제하는 구조는 서비스 몰입도를 떨어뜨릴 수 있다 (#206에 반영).
