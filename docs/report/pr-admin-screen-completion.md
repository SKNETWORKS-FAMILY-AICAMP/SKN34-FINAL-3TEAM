화면설계서에만 있던 관리자 전용 로그인·문의/공지 관리·결제/환불/PG 대조 화면을 실제 React 앱에 연결했습니다. 기존 운영·모델·정정·미션 기능은 유지하면서 흑백 관리자 메뉴로 통합했습니다.

## 주요 변경
- `/admin/login` 추가: 운영 모드는 Google 인증, 개발 모드는 가상 계정 로그인
- 권한별 관리자 메뉴 및 직접 URL 접근 제한, 노트북·태블릿용 흑백 레이아웃
- 문의 선택·답변 저장, 공지/점검 작성·수정·종료와 공개 대상·기간 설정
- 거래 내역·환불 요청·PG 대조 탭, 페이지 이동·새로고침, 승인 체크리스트와 최종 확인
- 실제 core 계약에 맞춘 환불 승인(본문 없이 Idempotency-Key)과 반려(reason) 요청
- APPROVED/202는 PG 확인 중, COMPLETED만 환불 완료로 표시. 미사용·7일 조건은 서버 검증에 위임
- 큐·DLQ와 작업 재처리의 중복 선택 표시 수정
- 학부모 로그인 하단 링크·가입 버튼·시연 안내의 간격 및 줄 배치 수정
- 새 API 어댑터·개발 전용 목업과 관리자 계약/권한 회귀 테스트 추가

## 한계 및 후속
- 현재 5242번 시연은 DEV 가상 데이터입니다. 실제 DB·Google OAuth·PG 조회/취소 통합 검증은 수행하지 않았습니다.
- core에 전체 예약·종료 공지 목록 API가 없어 공개 중인 관리자 대상 공지 첫 20건과 이 로그인 세션에서 작성·수정한 공지만 관리합니다.
- 결제 조회와 환불 승인 권한을 분리합니다. 조회 권한이 없는 환불 전용 계정은 목록에 접근할 수 없습니다.
- 기존 모델·정정 API와 학생 5개 테마는 변경하지 않았습니다. 별도 관리자 작업본 전체를 병합하지 않고 필요한 UI만 선별 반영했습니다.
- JS 청크 500kB 초과 경고가 남아 있습니다.
