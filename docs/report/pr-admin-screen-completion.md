화면설계서에만 있던 관리자 로그인·문의/공지·결제/환불 화면을 실제 React 앱에 연결하고, 학생 자기 평가와 관리자 미션 편집 요청을 learning 계약에 맞췄습니다. 공개 중인 미션을 수정해도 기존 미션·기준표 공개본은 유지되며, 검토·재게시한 뒤 새 시도부터 수정본을 제공합니다.

관련 이슈: #145, #146, #82 (연동 및 기존 변경 보존)

## 주요 변경
- Google 인증 관리자 로그인과 개발 전용 시연 로그인, 권한별 메뉴·직접 URL 접근 제한
- 흑백 관리자 레이아웃에 기존 운영·모델·정정·미션 기능 통합
- 문의 선택·답변 저장, 공지/점검 작성·수정·종료와 공개 대상·기간 설정
- 거래·환불·PG 대조 탭, 승인 체크리스트·최종 확인, 실제 승인/반려 요청 계약 적용
- 환불 승인 202/APPROVED는 PG 확인 중으로 표시하고 COMPLETED만 완료로 표시
- 학생 난이도 EASY/NORMAL/HARD 전송, 마무리 후 자기 평가 부분 저장·서버 확인과 비교, 답 단위·입력 틀 반영
- 입력 방식별 정답 객체 편집, 게시 누락 코드 한글 표시, 모든 문항 기준표·풀이 요소 조건 반영
- 미션/기준표의 편집본·공개본 구분, 재게시 전 공개본 유지, 미션 목록 페이지 이동
- 최신 #82 피드백 null·versions·재시도 제한과 #146 실제 judgmentId 신고 로직 유지
- 큐·DLQ 메뉴 중복 선택 및 학부모 로그인 하단 링크·버튼 간격 수정
- 화면설계서 10쪽 꾸미기 정책을 보상/유료 아이템 적용 여부는 추후 회의에서 결정하는 문구로 변경

## 한계 및 후속
- 브라우저 쓰기 검증은 DEV 가상 데이터 또는 운영 빌드의 API 대역입니다. 실제 DB·Google OAuth·PG·core/learning 통합 검증은 포함하지 않았습니다.

- JS 청크 500kB 초과 경고가 남아 있습니다.
