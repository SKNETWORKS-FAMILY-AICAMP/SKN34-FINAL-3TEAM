## 이번 구현과 검증

### 보완한 화면

- 학생·학부모·관리자 도움말, 공지, 문의·오류 신고와 처리 결과 확인을 역할별로 연결했다. 문제풀이·리포트·대화 화면에서 관련 항목을 선택한 상태로 신고할 수 있다.
- 관리자는 문의에 답변하고 공개 대상·기간을 지정하여 공지를 등록할 수 있다. 학부모에게 답변 알림이 연결되는 개발 목업 흐름을 제공한다.
- 학부모·관리자 알림 목록, 읽음·전체 읽음, 페이지 이동, 종류별 수신 설정을 추가했다. 실시간 SSE 수신은 이번 구현에 포함하지 않았다.
- 로그인 복구 안내, 학부모 계정 관리, 자녀 연결 해제·정보/기록 삭제 요청, 탈퇴 사전 확인·Google 재확인·접수 상태 확인 화면을 추가했다. 삭제·탈퇴 접수와 실제 삭제 완료를 구분한다.
- 관리자 모델·프롬프트 버전 등록에 구조화된 평가 근거와 적용 범위, 승인·활성화·되돌리기 흐름을 추가했다. AI 사용량은 실제 계약의 호출 종류와 미집계 비용을 구분한다.
- 개발 전용 `/review`에서 165개 요구사항 검색·상태 필터·페이지 이동과 역할별 시연을 제공한다.
