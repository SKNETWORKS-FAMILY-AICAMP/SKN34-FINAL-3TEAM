### 2.1 유형별 성취기준을 고른 근거

기획서 5.3(1)의 유형별 평가 요소에 가장 가까운 초5·6 성취기준을 골랐다. 문장은 교육부 고시 제2022-33호 기준이며, 이를 인용한 경기도교육청 「2026학년도 초등학교 5~6학년 1~2학기 수업-평가 계획 예시 자료」에서 2.1·2.2에 쓴 국어 9개·수학 2개 코드의 문구가 같은 것을 확인했다(2026-11-02, 7장 출처).

| 유형 | 성취기준 | 고른 이유 |
|---|---|---|
| 분석하기 | `[6국05-03]` | 소설·극의 인물·사건·배경을 파악하는 기준이라, 사건의 원인과 인물·사건의 관계를 설명하게 하면 평가 요소에 맞출 수 있음. 평가 요소 ① 원인·특징·관계, ② 까닭 잇기는 문장에 직접 없어 미션 질문에서 요구. `[6국02-02]`(생략된 내용 추론)는 읽기 이해 중심이라 보조 후보 |
| 따져 보기 | `[6국01-02]` · `[6국03-02]` | `[6국01-02]`는 기획서 5.3(1) 예시, `[6국03-02]`는 현재 시드(초6) 기준 |
| 새로 만들기 | `[6국05-05]` | "자신의 경험을 시, 소설, 극, 수필 등 적절한 갈래로 표현"하는 기준으로 평가 요소 ② 연결·변형에 가까움. ① 기존과 다른 생각, ③ 왜 나은지 설명은 문장에 없어 미션 질문에서 요구 |
| 문제 해결하기 | `[6수03-14]` (수학, 국어 우선의 예외) | 평가 요소(문제 정의·방법·결과 확인)가 풀이 틀과 맞고, 최종 답을 정답 키 규칙으로 모델 없이 판정할 수 있으며, 현재 시드·풀이 틀·기준표를 그대로 씀. 국어 `[6국02-04]`는 "다양한 관점의 글" 활용이라 따져 보기와 겹쳐 보조로 둠. "한 과목 먼저"와 충돌함을 확인하고 예외로 유지(#213 담당 결정, 11/2) |
| 돌아보기 | `[6국03-05]` · `[6국06-04]` | `[6국03-05]`는 기획서 5.3(1) 예시, `[6국06-04]`는 현재 시드(초6) 기준. `[6국05-06]`(삶과 연관 지어 성찰)도 후보 |

- 기본(수학 풀이) 문제 해결하기는 M2를 쓰지 않는다. 판정은 최종 답 규칙과 풀이 단계 LLM 근거 대조이며, 모델 교차 확인(M1)은 후순위다. 보조인 국어 서술 문제 해결 미션은 M2 입력 대상이다.
- 초3·4는 같은 방식으로 문구를 대조할 자료를 찾지 못해 성취기준을 정하지 않았다. M2를 쓰지 않는 학년이므로 미션 작성 시 고시 원문으로 정한다.

### 2.2 현재 데모 시드와 차이

[learning 보고서](learning.md) 1장의 시드(학년마다 유형별 1문항) 중 M2 입력 대상 학년인 초5·6:

| 유형 | 초5 현재 | 초6 현재 | 새 기본과 차이 |
|---|---|---|---|
| 분석하기 | 과학 `[6과07-02]` 서술 | 과학 `[6과14-02]` 고르기 | 과목 다름. 초6은 고르기라 M2 입력 대상 아님 |
| 따져 보기 | 국어 `[6국01-02]` 논술 | 국어 `[6국03-02]` 논술 | 같음 |
| 새로 만들기 | 도덕 `[6도03-02]` 서술 | 도덕 `[6도04-01]` 서술 | 과목 다름 |
| 문제 해결하기 | 수학 `[6수03-14]` 풀이 | 수학 `[6수03-19]` 풀이 | 과목·입력 같음(초6 성취기준은 1.5 예와 다름) |
| 돌아보기 | 국어 `[6국03-05]` 서술 | 국어 `[6국06-04]` 서술 | 같음 |

- 입력 형식 기준으로 지금 초5·6 시드 10문항 중 M2 입력 대상(서술·논술)은 7개(초5 4개, 초6 3개)이고, 새 기본으로 바꾸면 8개(문제 해결하기 2개 제외)가 된다. 실제 M2 적용은 평가를 통과한 범위만이다(FN-JDG-05). 도덕은 M2 서술 학습 데이터(71818: 국어·사회·과학·수학)에 없는 교과다.
- 후속 learning 이슈 범위: 분석하기(국어 서술로)·새로 만들기(국어로) 문항 교체와 기준표 요소.

| 주제 | 근거 | 문서 |

| 수치·표현 원칙 | 모든 건수·비율은 코드로 계산하고 기간·분자·분모·계산식·출처 유형을 함께 제공. 분모 5 미만은 비율 대신 개수만. 관찰된 답변 변화와 사고력 향상을 구분하고 검증 전 숫자 레벨·등급·순위 비표시. "사용 기간 동안의 변화"까지만 제시 | functional-spec 1.3·P08, 기획서 5.3(4) |

### 3.4 M2 중간 결과 (11/2 기준, 모델링 진행 중)

이 절의 숫자는 11/2 시점의 중간 결과다. 모델링이 진행 중이고 허용 기준도 정해지지 않아 통과·미달 판정은 하지 않는다. 활성화 판단(NFR-AIQ-06, 11/22) 전까지 숫자는 바뀔 수 있다.

| 구분 | 내용 |
|---|---|
| 정해진 것 | 처음 보는 주제 값을 대표로 함, 대표 숫자는 모델 대 전문가 평균 방식(#213 담당 결정 11/2), 사람끼리 값(데이터 성질이라 모델과 무관) |
| 정해지지 않은 것 | M2 허용 기준(3.4.1), 서비스 모델 버전(서술 3.0·논술 3.1, 서술 3개 평균 후보 있음) |
| 바뀔 수 있는 것 | 모델 숫자 |

정의

- M2 담당 보고 숫자는 Pearson 상관이며 "일치도"가 아니라 "상관"으로 부른다(M2 담당). 1이면 완벽하다. 일부 참고 값은 QWK(모델 대 1명 또는 사람 1대1)이며 표마다 적는다.
- 평가 글은 학습에 안 쓴 글이다. **처음 보는 주제**는 주제 자체가 학습에 없던 글만 모은 평가로, 자체 미션에 M2를 쓰는 서비스 상황에 해당한다. 대표 숫자는 처음 보는 주제 값으로 한다.
- **서비스용 모델과 평가용 모델**: 서비스 후보 모델은 모든 주제를 학습하므로 처음 보는 주제를 평가할 수 없다. 처음 보는 주제 값은 같은 설정으로 일부 주제(논술은 시드 43으로 10개)를 빼고 학습한 평가용 모델에서 낸다(`train_545.py --n-new`, 0이면 서비스용).
- 사람끼리는 전문가 1명 대 1명(1대1)이 기준선이고, 1명 대 나머지 평균은 참고다.
- 모델 숫자는 두 방식이 있다. **모델 대 1명**(채점자마다 구해 평균, M2 담당의 QWK 값도 이 방식)과 **모델 대 전문가 평균**(M2 담당 보고 방식)이다. 같은 글이라도 값이 다르므로 표마다 방식을 적는다. 전문가 평균은 채점자 한 명의 흔들림이 줄어 보통 값이 더 높게 나오며, 모델이 더 좋다는 뜻은 아니다.
- **발표 대표 숫자는 모델 대 전문가 평균 방식**으로 한다(#213 담당 결정 11/2). 이 보고서의 다른 M2 숫자(서술 0.685, 논술 0.700)와 같은 방식이다.

#### 3.4.1 허용 기준 (검토 중)

M2 허용 기준은 정해지지 않았다. 기획서 5.2는 11/1 모델 확정 전까지 허용 기준을 정하고 11/22에 활성화를 판단하도록 했고, NFR-AIQ-06은 11/22까지 기준을 정하도록 한다. 기획서 기한(11/1)은 지났고, 기준 지표(기획서는 QWK, 지금 M2 보고는 Pearson)도 정해지지 않았다. #213 담당 작업용 기준안(Williamson, Xi & Breyer 2012 기반, 팀 미검토, 저장소 밖)이 있으나 팀이 정한 기준이 아니다(5장).

- 학습한 주제만 출제하는 문항 은행 방식은 학년별 주제가 서술 12개·논술 6개뿐이라 어렵다고 판단했다(M2 담당).
