# 학부모 대시보드 시안 적용

작성일: 2026-10-27. 기준: 학부모 대시보드 시안(옅은 초록 바탕 + 초록 포인트), FN-DSH-06~10, [API 명세 2.3](../design/api-spec.md#23-대시보드-fn-dsh).

학생 화면과 달리 장식 없이 흰 패널·얇은 테두리·숫자 중심으로 정리했다. 조회 API와 집계 규칙은 바꾸지 않았다.

## 구성

- 학부모 화면 공통 배치: 왼쪽 메뉴(대시보드·공책, 기록에 물어보기, 주간 리포트, 정보 관리, 자녀 기기·PIN)와 이용권, 위쪽에 자녀 선택·자녀 등록·이 자녀로 학습 시작·로그아웃. 관리자 화면은 기존 배치 유지
- 대시보드
  - 머리: 자녀 이름·학년·서버가 돌려준 실제 조회 기간
  - 상태 줄: `QueryState`(표본 부족·기록 없음)와 "관찰 기록이며 사고력 진단이 아닙니다"
  - 지표 3개: 서버 Metric 2개(답을 남긴 활동, 생각을 덧붙인 활동)와 관찰된 생각 유형 수. 비율은 서버가 값을 줄 때(표본 5건 이상)만 표시하고, 아니면 분자/분모 건수로 표시. 카드마다 집계식 문장
  - 다섯 가지 생각 활동: 유형별 관찰·미관찰과 해당 기록 바로가기(원문 창)
  - 주간 리포트 카드: 최신 리포트 기간·판·생성 상태, 이용권별 안내, 리포트 열기·기록에 물어보기(같은 자녀·기간 유지)
  - 학습 기록 표: 날짜·미션·유형·답변 수(보완 수)·되묻기·돌아보기·상태·원문 보기. 좁은 화면에서는 표만 상자 안에서 가로로 넘김

## 결정

- "관찰된 생각 유형 n/5"는 기존 유형별 응답(`thinking-types`)의 관찰 유형 수를 센 것으로, 새 서버 계산이 아니다.
- 기존 테스트의 대시보드 제목("…의 기록을 함께 살펴보세요.")과 원문 버튼 이름("답변·되묻기·돌아보기 보기")은 "…의 학습 기록", "{미션} 원문 보기"로 바뀌어 테스트를 맞췄다.
