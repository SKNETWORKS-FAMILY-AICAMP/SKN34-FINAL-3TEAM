# 학생 화면 테마 적용 (생각 지도 캔버스)

작성일: 2026-10-27. 기준: 테마 캔버스 "사고뭉치 생각 지도 프로토타입"(홈·미션·꾸미기, 테마 5종, 캐릭터 5종), [API 명세 3.12](../design/api-spec.md#312-학생-화면-꾸미기-설정-목업-계약-초안-백엔드-확인-대기).

학생 화면 전체를 캔버스의 테마 세계로 바꿨다. 학습 로직(초안 저장·제출·피드백·마무리·돌아보기)과 API 계약은 그대로이고 화면 구조와 문구만 바뀌었다.

## 화면

| 경로 | 내용 |
|---|---|
| `/student/home` 생각 지도 | 오늘의 미션 카드(이어할 시도 → 진행 중 → 시작 전 순서) + 다섯 생각 유형이 지도 위 한 곳씩. 곳마다 "끝낸 미션 n"(홈 응답의 미션 상태로 센 수, 레벨·점수 아님)과 "오늘 여기!" 표시. 곳을 누르면 그 유형 미션만 보기 |
| `/student/missions?type=` 미션 고르기 | 유형 칩·과목 필터, 장면 그림이 있는 카드, 상태(시작 전·하는 중·끝냈어요) |
| `/student/journal` 내 공책 | 기존 기록 카드를 종이 위에 표시 |
| 꾸미기 (생각 지도 안의 창) | 첫 화면 오른쪽 아래 "꾸미기" 버튼으로 연다. 테마 5종(호수·숲·공장·소행성·바닷속), 캐릭터 5종(뭉치·토리·몽돌·콩이·몽글). 누르는 즉시 뒤의 지도에 반영·저장. 별도 메뉴·경로는 두지 않는다 |
| `/student/attempts/:id` 미션 | 단계 표시(내 생각 쓰기 → 한 걸음 더 → 돌아보기), 메뉴 숨김. 위에서 아래로 질문(캐릭터 말풍선) → 장면 → 도움 버튼 → 내 생각 칸. 제출 버튼은 아래에 고정 |
| `/student/login` PIN | 로그인 전이라 학생 설정을 모르므로 기본 테마(호수) 위에 표시 |

## 결정

- 문제 화면은 캔버스의 2단 대신 위아래 배치를 유지했다(이전 "옆에 있으면 보기 어렵다" 피드백, 사용자 재확인).
- 캐릭터는 캔버스대로 5종을 넣었다. 질문·되묻기·생각 열기를 말풍선으로 보여 주는 역할만 하고 대화 기능은 없다. 되묻기 말풍선에도 출처(AI 질문·질문 은행)를 그대로 표시한다.
- 캔버스의 학년·단계 전환은 시안용 조절 장치였다. 실제 화면에서는 학년은 자녀 정보, 단계는 시도 상태(답변 수·마무리 여부)에서 정해지며 아이가 임의로 바꿀 수 없다.
- 꾸미기는 사용자 요청으로 별도 메뉴 대신 첫 화면(생각 지도)에서만 관리한다. 고르는 동안 뒤의 지도가 바로 바뀌어 결과를 보며 고를 수 있다.
- 문구 변경: 메뉴 "학습 홈" → "생각 지도", 제출 버튼 "답변 제출" → "다 썼어요"(보완 답은 "더해서 보내기"). 기존 브라우저 테스트도 맞춰 고쳤다.
- 사용하지 않게 된 `StudentDashboard.tsx`를 지웠다. `feature/fe-playful-design`의 stash가 같은 파일을 고치므로 그 stash를 나중에 적용하면 충돌한다.

## API 명세 추가 (3.12)

- `GET/PUT /students/me/preferences` `{theme, companion, updatedAt}`. 학생 토큰 전용, 목록 밖 값 422. 기존 명세와 경로·규칙 충돌을 확인했다(`/students/me/*`에 같은 기능 없음, 레벨·등급 비표시 원칙과 무관).
- 대응 FN 항목이 없는 제안이라 기능 명세 반영과 저장 위치(core 학생 테이블 컬럼 또는 별도 테이블)는 백엔드 확인 대상이다.
- MSW 목업은 학생별 값을 `sessionStorage`의 `sagomungchi:msw-look:v1`에 둔다. 운영 번들 제외를 `tests/production-mocks.mjs`가 검사한다.

## 남은 점

- 장면 그림은 코드로 그린 임시 그림이다. 내 공책 카드의 펠트 사진은 기존 자산을 그대로 쓴다.
- 홈 지도는 넓은 화면(1240px 이상)에서 카드와 지도를 나란히, 태블릿에서는 위아래로, 820px 이하에서는 섬을 목록으로 접는다. 실제 태블릿 기기 확인은 하지 않았다.
- 꾸미기 설정 API는 목업 계약 초안이며 실제 백엔드와 연동하지 않았다.
