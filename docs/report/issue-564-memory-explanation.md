# #564 추억 설명 근거·검증 내부 API

## 기준과 범위

- #563 브랜치에서 시작했으며 PR #582 병합 후 develop `1664b668`을 fast-forward로 반영했다. 기존 #563 코드와 파일 내용 차이는 없었다.
- 선행 #565 PR #580의 AI 설명 API, #566 PR #572의 core 프록시 계약을 사용한다.
- learning 설명 API 구현 범위다. 프론트 화면·운영 배포·대표 평가셋 품질 승인은 포함하지 않는다.
- 새 DB 테이블·마이그레이션·패키지 의존성 없음. #563 V20 검색 문서와 #559 액자를 재사용한다.

## 동작과 결정

1. 질문 1~200자, 서로 다른 시도 UUID 1~3개를 받는다. null·중복·범위 밖 개수는 400이다. 학생 scope를 먼저 검사한다.
2. 본인 READY 문서, 보유 액자, KST 지난 주, 완료된 THEME_DAY/REVIEW 조건을 확인한다. 선택 ID가 범위 밖이면 외부 호출 전 422 VALIDATION_FAILED다.
3. 공백 제외 20자 미만 답변은 근거에서 뺀다. 남는 근거가 없으면 외부 호출 없이 INSUFFICIENT다. 20자는 점수 기준이 아니라 설명할 서술을 확보하기 위한 초기 기준이다.
4. 질문을 마스킹한 뒤 임베딩을 생성해 선택 문서의 관련도를 다시 계산한다. 같은 임베딩 모델의 유효 근거가 없거나 최고 관련도 0.35 미만이면 설명 LLM을 부르지 않고 INSUFFICIENT다. 질문을 저장하지 않으므로 관련도 재확인용 임베딩 호출은 필요하다.
5. 요청 순서대로 유효 근거 번호를 1부터 다시 매긴다. 제목 200자·질문 앞부분 2,000자·최종 답변 앞부분 2,000자·회차 주를 보낸다. 닉네임·UUID는 자르기 전에 마스킹한다. 생성 요청 본문에 학생·시도·답변 ID는 없다.
6. 문장별 번호가 요청 범위에 있고, 큰따옴표 인용이 해당 문장의 근거 원문에 있을 때만 GENERATED다. 번호 누락·중복·범위 밖·인용 불일치·ai 422/502는 FAILED, text=null·citations=[]다. 정형 설명으로 대체하지 않는다. 프로필·질의 임베딩 실패와 생성 ai 503·시간 초과·연결 실패·서킷 열림은 503 AI_UNAVAILABLE로 core 하루 사용량을 되돌린다(#592, retention-expansion 13.1).
7. 임베딩 후와 생성 후에 범위·근거 내용을 재조회한다. 도중 삭제·변경되면 생성 결과를 반환하지 않는다.
8. 검증한 번호만 themeId·weekStart·attemptId로 변환한다. 질문·설명은 저장하거나 원문 로그에 남기지 않는다.

### 설정과 대기 시간

- `MEMORY_EXPLANATION_MIN_ANSWER_CHARS`: 기본 20, 1~2,000 허용.
- `MEMORY_MINIMUM_SIMILARITY`: 기본 0.35, #563과 공유. 대표 평가셋 최종 조정은 #568.
- 설명 처리 시작부터 35초 예산에서 프로필·질문 임베딩 시간을 차감해 AI 생성의 read timeout에 전달한다. 생성 호출은 최대 35초, 클라이언트 재시도 없음, 별도 `ai-memory-explanation` 서킷을 사용한다.
- DB 조회·전송 취소 정리까지 포함하는 엄격한 전체 응답 상한은 아니다. core의 기존 설명 경로 45초를 변경하지 않는다.

## 실제 외부 AI 연동

가상 학생의 도서관 글만 사용했다. 운영 DB와 AWS를 사용하지 않았다.

- 임베딩: OpenAI `text-embedding-3-small`, 1536차원.
- 설명: OpenAI `gpt-6-luna`, 프롬프트 `memory-explanation@1`.
- 전체 연결: 합성 완료 기록 → 실제 임베딩 → READY 저장 → 질의 임베딩 → 실제 LLM → learning 번호·인용 재검사 → 실제 회차·시도 반환.
- 실제 연동 시험 2회 모두 GENERATED. 질의 임베딩부터 설명 반환까지 3,431ms / 2,667ms(각각 단건 측정, 문서 사전 적재 시간 제외).
- AI API 단독 추가 확인: 2,543ms. “책을 빌리려면 버스로 삼십 분이나 가야 해요.”를 제공된 근거 그대로 인용하고 [1]로 연결했다.
- 전체 응답 예: “우리 동네에 도서관이 필요한 까닭을 생각해 보고, 책을 빌리려면 버스를 타고 삼십 분이나 가야 해서 불편하다고 답했어요[1]. 가까운 도서관이 생기면 친구와 책을 읽고 숙제도 할 수 있다고 했어요[1].”
- 실행 증거는 로컬 테스트 로그·JUnit XML·합성 응답 JSON에 보관했다. API 키·실제 학생 정보는 커밋하지 않는다.

단건 합성 시험은 서비스 전체 품질·지연의 보장이 아니다. 사용량 RabbitMQ 전달·AWS 배포·실제 브라우저 흐름은 이번 검증에 포함하지 않았다. 대표 평가셋에서의 설명 근거 일치·생성 활동 여부 사람 평가는 #568 범위다.
