## 1. 공통 정의

### 1.1 역할·권한

| 자원 | 학생 | 학부모 | 관리자 |
|---|---|---|---|
| 학습 기록 (답변·판정·되묻기·돌아보기) | 본인 기록만 작성·조회 | 연결된 자녀 기록만 조회 | 서비스 운영 권한이 신고·문의에 연결된 시도만 열람, 열람마다 감사 기록 (P07) |
| 분석 대화·주간 리포트 | 불가 | 연결된 자녀만 | 처리 상태만 |
| 미션 콘텐츠 | 공개된 미션 조회 | - | 콘텐츠 운영 권한: 작성·검토·공개·중단 |
| 결제·구독 | 불가 | 본인 거래만 | 결제 운영 권한: 조회·환불 처리 (조회·환불 권한 구분) |
| 신고·문의 | 본인 접수·조회 | 본인 접수·조회 | 검토·답변 |
| 알림 | 본인 알림 | 본인 알림 | 공지 등록 |
| 모델·프롬프트 버전 | - | - | 서비스 운영 권한 |

- 관리자 권한은 승인된 계정에만 부여, 일반 가입 과정에서 선택 불가 (FBN-02)
- 콘텐츠·결제 운영 권한만으로 학생 원문 학습 기록 열람 불가

### 1.3 공통 처리 규칙
- 권한 검사: 학생은 본인, 학부모는 연결된 자녀 기록만. 화면 요청·에이전트 도구 호출·리포트·다운로드 모두 동일 검사, 다른 식별값 요청은 거부 (FBN-01)
- 수치 근거: 모든 건수·비율은 코드로 계산하고 기간·분자·분모·계산식·출처 유형(기록·규칙·정답 키·AI 관찰)을 함께 제공
- 상태 구분: 기록 없음·표본 부족·판정 보류·처리 실패를 서로 다른 상태로 처리, 확인되지 않은 값을 임의로 채우지 않음
- 효과 표현: 관찰된 답변 변화와 사고력 향상을 구분, 검증 전 숫자 레벨·등급·순위 비표시
- 대체 응답: 1.4 P16에 정한 지점만 허용, 그 외 자동 대체 금지. 대체 시 실패 사실·출처(llm·llm_retry·bank·template)·조회 근거 표시
- 생각 유형: 분석하기·따져 보기·새로 만들기·문제 해결하기·돌아보기 5개를 전 기능 동일 사용, 비교·분류·순서·규칙·원인과 결과·추론은 기초 사고력으로 구분 (FAD-05)

### 1.4 확정 정책

| P | 항목 | 확정 내용 |
|---|---|---|
| P01 | 학생 진입·계정 | 학생 별도 계정 없음, 학부모 로그인 → 자녀 선택 → 학생 세션 발급. 시연 링크(`?student=`) 폐지. 자녀 등록 필수: 별명·학년·출생연도. 자녀는 전원 만 14세 미만으로 간주, 등록 시 법정대리인(학부모) 동의 저장 |
| P02 | 보호자 연결·다자녀 | 다른 보호자의 기존 자녀 연결 미지원(자녀는 등록 보호자 1명에만 소속). 학부모당 자녀 최대 3명. 상단 전역 자녀 전환, 대시보드·대화·리포트 공통, 마지막 선택 자녀 기억 |
| P03 | 학년·문항·음성 | 지원 학년 초3~6. 시연 초3·초5 각 5문항(생각 유형별 1문항). 서술·풀이 단계 틀 전 학년, 논술 틀 초5~6. 음성 시범(STT) 미구현, 질문 읽어주기는 브라우저 TTS로 전 학년 |
| P04 | 마무리·되묻기 | 마무리 조건: 판정 처리 완료(`DONE`, 보류 포함) 1회 이상. 되묻기 최대 2회, 도달 시 마무리 안내. 고르기 정답 시 되묻기 없이 즉시 마무리 가능, 되묻기 건너뛰기("이대로 돌아보기") 허용. 마무리 후 답변 제출 불가. 돌아보기는 난이도 필수·달라진 점 선택, 저장 시 학습 완료 |
| P05 | 생각 메모 | 초안과 함께 서버 자동 저장, 학생 본인만 열람(판정·리포트·학부모 화면·분석 대화 미노출) |
| P06 | 주간 리포트 | 주 경계 KST 월 00:00~일 23:59:59, 다음 주 월요일 07:00 생성. 기록 없는 자녀도 "기록 없음" 리포트 생성(LLM 미호출). 재생성은 새 판 추가·최신본 기본 표시·이전본 열람 가능, 학부모 리포트당 1회·관리자 무제한. 분석 대화 기본 기간 최근 7일(오늘 포함). 다운로드 PDF·Markdown |
| P07 | 관리자 권한 | 학생 원문은 서비스 운영 권한이 신고·문의 연결 시도만 열람(감사 기록). 미션 검토·게시는 콘텐츠 권한 1인 가능(작성자 포함). 검토 요청은 별도 요청으로 전환. 게시 중 수정본은 재검토·재게시 후 신규 시도부터 적용, 진행 중 시도는 시작 당시 버전 유지. 작업 재처리는 서비스 운영 권한 전원 |
| P08 | 수치 집계 | 대상: 기간 내 답변 제출 1건 이상인 시도(완료·미완료, 완료 여부 별도 표시). 제외: 처리 실패만 있는 시도·삭제 기록. 분모 5 미만은 비율 대신 개수만. 전후 변화는 시도당 최초 vs 마지막 답변: 글자 수(공백 포함)·문장 수(`.` `?` `!`·줄바꿈 기준 비지 않은 덩어리)·까닭을 잇는 말(고정 목록 문자열 매칭 횟수). 도움 없이 시작한 비율 = 최초 답변 전 도움 열람 없는 시도 / 집계 대상 시도 |
| P09 | 삭제·보관·탈퇴 | 자녀 기록은 물리 삭제 + 삭제 표식(근거 "이용 불가"). 삭제는 재확인 후 확정, 학습·리포트 서비스의 삭제 완료 수신 시 완료. 학습·대화·리포트는 이용 중 보관·탈퇴·삭제 시 즉시 파기, 결제 거래 기록만 5년 보관(전자상거래법). 필수 동의 철회 시 해당 자녀(또는 계정) 이용 차단 후 삭제·탈퇴 별도 안내, 선택 동의 철회는 해당 기능만 중단. 진행 중 구독·미처리 환불이 있으면 탈퇴 요청 불가, 요청 즉시 처리(취소·로그인 불가) |
| P10 | 신고·알림·경보 | 신고 유형 5종: 판정이 틀려요·질문이 이상해요(정답 노출·어려움 포함)·숫자·인용이 달라요·부적절한 표현·기타. 사용자 알림은 앱 내 알림만, 유형별 수신 on/off. 운영 경보는 Grafana Alerting → 팀 디스코드, 담당은 인프라 1명 + 서비스별 담당 |
| P11 | 평가·기기 | LLM 판정 대상(서술·논술) 미션당 예시 답안 20개·평가자 2명. 지원 기기 PC(Chrome)만 |
| P12 | 운영 수치 | LLM 1회 15초·재시도 1회(1초 대기). learning→ai 판정·되묻기 각 35초, core→learning 피드백 80초. 판정 리스 90초·고착 탐지 1분. 분석 대화 첫 응답 20초·전체 120초. 서킷 브레이커 최근 20건 중 실패 50% 이상 시 30초 차단. 리포트 작업 재시도 3회(1·5·15분) 후 DLQ. 멱등 키 24시간. 백업 RDS 자동 백업(일 1회)+PITR 7일, RPO 5분·RTO 4시간. 사용 한도는 P13 |
| P13 | 상품·청구 | 무료 + 프리미엄(자녀 1명 월 14,900원, 자녀별 구독). 가격·기능·한도는 상품 데이터로 관리(변동·요금제 추가 대비), 구독은 결제 당시 상품·금액 기록. 무료: 하루 미션 3개·분석 대화 없음·리포트 수치만. 프리미엄: 하루 피드백 50회·분석 대화 30회·리포트 전체. 월 LLM 비용 예산 80% 도달 시 운영 경보. 청구일은 최초 결제일 기준 매월 같은 날(없으면 말일), 매일 09:00 KST 청구. 갱신 실패 시 유예 3일(이용 유지)·매일 1회 최대 3회 재청구, 모두 실패 시 해지 |
| P14 | 해지·환불 | 자동 갱신 해지 시 이용 기간 끝까지 유지 후 무료 전환, 기간 중 해지 철회 가능. 환불은 결제 7일 이내 + 결제 후 프리미엄 기능 미사용 시 전액만(부분 환불 없음). 환불 완료 시 구독 즉시 해지 |
| P15 | 모델 | M1 확신도 0.8. M2 klue/roberta-base. 설명 sLLM은 이번 범위 제외 |
| P16 | 대체 응답 | 되묻기 유출 검사 재생성 실패 → 중립 질문 은행. 판정 LLM 실패 → 대체 없이 처리 실패·재요청. 분석 대화 대조 실패·LLM 장애 → 규칙 응답 모드(계산 수치·원문 목록 템플릿). 리포트 요약 대조 실패 → 템플릿 요약으로 발행 |
