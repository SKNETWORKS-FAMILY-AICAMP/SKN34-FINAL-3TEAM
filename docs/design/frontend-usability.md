# 학부모 화면 사용성 기준 (#426~#429)

- 기존 `achromatic-ledger` 방향(seed `683525200`)과 사고뭉치 로고·글꼴을 유지한다. 탐색은 중립색, 강조색은 주요 행동과 상태에 쓴다.
- 기본·보조 버튼은 테두리와 배경으로 링크와 구분하고 누르는 영역은 최소 44px로 한다. 본문·버튼 문구는 읽을 수 있는 크기를 유지한다.
- 학습 현황은 활동 수치, 리포트는 생성된 문서, AI 챗봇은 기간을 선택한 질문에 답한다. 날짜 필터는 기록·대화에만 둔다.
- `/parent/settings`의 프로필·공개/동의·계정 관리 탭을 유일한 설정 화면으로 사용한다. 예전 `/parent/account`는 기존 자녀·조회 조건을 보존해 계정 관리 탭으로 보낸다. 이용 동의 전에도 계정 관리·탈퇴 진입은 유지한다.
- 원문 비공개일 때 원문 조회·질문·다운로드를 요청하지 않고 이유와 사용할 수 있는 기능을 안내한다. 공개 권한은 자녀가 결정한다.
- 오류는 사용자 안내와 가능한 재시도를 먼저 보여 준다. 오류 코드·확인 번호·상세 응답은 접힌 자세히 영역에 둔다.
- 신규 결제는 상품·가격·1개월 기간·자녀 수·기능 확인 → 자녀 선택 → 첫 달 결제 → 별도 자동결제 등록 순서다. 자동결제가 기본 등록된 것처럼 안내하지 않는다.
- 상품이 없으면 구매 폼과 빈 주문 요약을 숨긴다. 설정 장애·비활성 버튼은 사용자에게 사유와 문의 경로를 제공하며 키 값은 표시하지 않는다.
- 상태는 한글로, 자녀는 별명으로 표시한다. 주문번호는 접힌 거래 상세에 둔다. 모바일에서 본문 가로 넘침이 없어야 한다.
- 1440·768·390px에서 기본·비공개·빈 목록·실패 상태와 설정 경로를 확인한다. 가상 결제 검사와 실제 PG 검증은 구분한다.

## 2026-11-10 동선 통합

- 학부모 리포트와 AI 챗봇은 `/parent/report` 한 메뉴 안에서 리포트 보기·질문하기로 이동한다. 선택한 리포트의 자녀·기간을 같은 챗봇에 연결하며, 일일 리포트의 고정 범위·최신판 계약과 원문 공개/이용권 권한을 유지한다. `/parent/analysis`는 기간을 보존해 질문 화면으로 연결한다.
- 사고뭉치 로고는 로그인 역할에 맞는 홈으로 연결한다. 자녀 추가 등록은 계정·자녀 설정의 프로필에서 한다.
- 알림은 상단 우측 끝의 종 버튼으로 연다. 같은 알림 창에서 목록·읽음 처리·수신 설정을 이용한다. 학생은 보호자 알림에 접근하지 않는다.
- 자녀 PIN은 선택한 자녀 한 명의 폼만 표시한다. 자녀 선택은 줄바꿈 가능한 알약 버튼과 키보드 이동을 제공한다. 사용자의 명시적 요청으로 PIN 저장의 추가 재인증을 제거하며, 서버의 활성 보호자 세션·현재 자녀 권한·PIN 규칙·잠금 해제·감사는 유지한다. 보호자 비밀번호·삭제·탈퇴의 재인증은 별개다.
- 기존 `achromatic-ledger` 배치·사고뭉치 로고·글꼴을 이어 사용한다. 이번 화면의 주 작업은 리포트에서 질문으로 이어지는 흐름이며, 임의 생성 자료나 새 시각 스타일은 추가하지 않는다.
