## 1. 기능 한 줄 요약

유료 구독 학부모가 자녀의 추억 앨범 한 회차(주간 테마 한 주)를 그림책 PDF로 발급받는다. 시작 그림, 요일별 장면 그림과 문제·아이 답변(채팅 모양), 끝 이야기가 A4 가로 8쪽에 담긴다. 새 그림이나 LLM 문장은 만들지 않고 이미 있는 그림과 기록만 배치한다.

## 4. E3 확인 결과 (11/24, 합성 데이터)

`backend/report-service`의 표본 회차(`scripts/memory_book_sample.py`)에서 월요일 답만 길게 바꿔 PDF를 만들고, 표지 목차의 쪽 번호와 실제 PDF 쪽을 대조했다. 기준 PDF는 8쪽이다.

| 월요일 답 | PDF 쪽 | 목차 |
|---|---|---|
| 답 1개 40~500자 | 8 | 맞음 |
| 답 1개 550자 | 9 | 화요일부터 끝까지 번호가 1씩 밀림 |
| 답 2개(되묻기 1번) 합 400자 | 9 | 밀림 |
| 답 3개 합 450자 | 9 | 밀림 |
| 답 4개 합 1,400자 | 11 | 밀림 |
| 답 2개 합 1,000자 + 등장인물 대사 3줄 | 10 | 밀림 |

- 한 날의 대화 칸은 대략 **한 번에 쓴 답 500자, 되묻기가 있으면 합 400자** 안쪽이면 한 쪽에 들어간다. 넘으면 그 날이 두 쪽이 되고 뒤 목차 번호가 모두 밀린다. 엔딩 전 회차도 같다.
- 논술형(중학년 이상)에서는 드물지 않을 수 있어 실제 답 길이 분포를 보고 정한다(E3, 측정 뒤 결정).
