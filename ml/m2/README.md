# M2 글 점수 모델

지시문과 학생 글을 받아 분석적 평가 8개 항목을 1~5점으로 매기는 모델의 학습·평가 코드 (이슈 #4).
서빙(scoring-service)은 이 폴더 범위가 아니며, 여기서는 학습과 평가만 한다.

> AI Hub 원본·가공본·노트북·모델 가중치는 저장소에 넣지 않는다 (NFR-DAT-03). `.gitignore`로 막혀 있다.
> AI Hub 데이터는 외부 LLM API로 보내지 않는다.

## 폴더 구조

```
ml/m2/
├─ scripts/
│  ├─ build_tables.py   # AI Hub 라벨 zip → 학습용 표 (data/)
│  ├─ split.py          # 문항 단위 학습/검증/평가 분할 (splits/)
│  ├─ baseline.py       # 기준선 평가 (results/)
│  ├─ train.py          # roberta 파인튜닝 (checkpoints/, results/)
│  └─ latency.py        # CPU 추론 속도
├─ data/                # (커밋 안 함) build_tables.py 출력
├─ splits/              # (커밋 안 함) split.py 출력, 스크립트로 재현
├─ results/             # (커밋 안 함) 평가 결과 CSV
├─ checkpoints/         # (커밋 안 함) 학습한 모델 가중치
├─ notebooks/           # (커밋 안 함) 탐색용
├─ pyproject.toml
└─ uv.lock
```

## 실행

```bash
cd ml/m2
uv sync

# 1) AI Hub 라벨 zip → 표 (zip은 풀지 않아도 됨, 원천 데이터는 읽지 않음)
uv run python scripts/build_tables.py \
  --descriptive-zip "<25.서술형 글쓰기 평가 데이터.zip>" \
  --essay-zip "<26.논술형 글쓰기 평가 데이터.zip>"

# 2) 문항 단위 분할 (시드 42, 이미 있으면 같은지 비교만 함)
uv run python scripts/split.py

# 3) 기준선
uv run python scripts/baseline.py

# 4) 파인튜닝 (GPU 있으면 자동으로 GPU, 없으면 CPU)
uv run python scripts/train.py --model klue/roberta-base
uv run python scripts/train.py --model xlm-roberta-base
#    동작 확인만: --limit 200 --epochs 1 --max-length 256

# 5) CPU 추론 속도
uv run python scripts/latency.py --model klue/roberta-base
```

모든 스크립트는 `--data-dir`, `--out-dir` 등으로 경로를 바꿀 수 있다 (로컬·RunPod 공통).

## 분할

같은 문항의 답이 학습과 평가에 섞이면 주제 단어를 외워 점수가 부풀려지므로 **문항 단위**로 나눈다.
AI Hub 원래 분할은 검증 문항이 학습에도 들어 있어(서술형 60/60, 논술형 89/90) 쓰지 않는다.

| | 방식 | 학습 | 검증 | 평가 |
|---|---|---|---|---|
| 서술형 | 학년×과목 20칸(칸마다 3문항)에서 1문항씩 빼고, 뺀 20문항을 바둑판 모양으로 검증·평가 | 40문항 (66.1%) | 10 (17.6%) | 10 (16.3%) |
| 논술형 | 글종류×학년 칸마다 앞 20% 평가, 다음 20% 검증 | 53문항 (53.2%) | 18 (23.3%) | 18 (23.4%) |

- 학년·과목·글 종류가 평가용에 고르게 들어가는지, 한 문항이 두 세트에 걸치지 않는지 확인함
- 평가용은 고정하고 마지막 성적에만 쓴다

**누수 확인**: 같은 TF-IDF+로지스틱 모델의 서술형 총점 QWK가 우리 분할 0.136, AI Hub 원래 분할 0.394.

## 지표

- **QWK**: 모델 vs 전문가1, 모델 vs 전문가2의 평균. 천장(전문가1 vs 전문가2)과 같은 조건으로 비교
- **균형정확도·과대·과소**: 정답 = 두 전문가 평균 반올림(3.5 → 4)
- 전체, 학년별, 글 종류별(논술형)로 보고

## 모델 입력·출력

- 입력: `[학년] {grade} [지시문] {prompt}` + 학생 글 (scoring-service API `{prompt, text, grade}`와 같음). 512토큰을 넘으면 학생 글 뒤쪽을 자름
- 출력: 총점 + 8개 항목 점수를 숫자로 맞히는 회귀 → 반올림, 범위 밖은 자름 (총점 1~4, 항목 1~5)
- 정답: 두 전문가 평균. 검증용 평균 QWK가 가장 좋은 에폭의 가중치를 저장
- 주의: klue/roberta 토크나이저는 두 번째 문장에 `token_type_ids=1`을 붙이지만 모델은 0만 받는다. 추론할 때 `input_ids`, `attention_mask`만 넘길 것 (그대로 넘기면 `IndexError`)

## 모델 라이선스

| 모델 | 라이선스 | 비고 |
|---|---|---|
| klue/roberta-base | 모델 카드에 표기 없음 | KLUE 저장소·klue/bert-base는 CC BY-SA 4.0. KLUE 논문은 상업적 이용 허용 명시 |
| xlm-roberta-base | MIT | 기준선·대안 |

- klue/roberta-base는 KLUE 저장소 라이선스(CC BY-SA 4.0)를 따르는 것으로 보고 사용한다.
  - 출처 표시(BY): 서비스·발표 자료에 KLUE(Park et al., 2021) 표기
  - 동일 조건 공유(SA): 파인튜닝 가중치는 S3에서 내부 추론에만 쓰고 외부에 배포하지 않는다
- 모델 카드에 라이선스가 없으므로 팀 확인 후 확정. 문제가 있으면 xlm-roberta-base(MIT)로 대체
- 확인일: 2026-10-26
